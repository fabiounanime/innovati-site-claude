# Innovati Automação — site institucional

Site estático responsivo, pronto para publicação no Cloudflare Pages.

## Publicação

1. Envie todo o conteúdo desta pasta para a raiz do repositório GitHub.
2. No Cloudflare Pages, conecte o repositório.
3. Em **Build command**, deixe em branco.
4. Em **Build output directory**, use `/` (raiz).

Não há dependências, instalação ou etapa de compilação.

## Estrutura

- `index.html`: página institucional principal.
- `downloads.html`: central de downloads.
- `css/styles.css`: identidade visual e responsividade.
- `js/main.js`: menu mobile, animações, formulário e WhatsApp.
- `assets/img`: logo da Innovati e logos dos clientes.
